Install Klear (v0.1.20)

Download

Download package

klear-v0.1.20.zip · then follow the steps below

We’re submitting Klear to the Chrome Web Store. Approval usually takes about two weeks. Install from the download above to use Klear in Gmail until then.

Quick checklist

  • Unzip to a permanent folder with manifest.json at the root
  • Open chrome://extensions → turn Developer mode on
  • Load unpacked → select that folder → see Klear 0.1.20
  • Click the Klear icon → Connect with Portal
  • Open Gmail in the same Chrome profile and refresh

1. Unzip the file

  1. Double-click klear-v0.1.20.zip on your Desktop (or wherever it is).
  2. Move the unzipped folder somewhere permanent, e.g. ~/Documents/Chrome-Extensions/klear-v0.1.20.
  3. Open the folder and confirm manifest.json is inside it (not in a nested subfolder).

2. Load the extension in Chrome

  1. In Chrome, go to chrome://extensions.
  2. Turn Developer mode on (top-right).
  3. Click Load unpacked and select your folder.
  4. Accept any permission prompts Chrome shows.

3. Connect your account

  1. Click the Klear icon in the toolbar (pin it from the puzzle menu if needed).
  2. Click Connect with Portal and sign in.

4. Open Gmail

  1. Open Gmail in the same browser profile.
  2. Refresh the tab if Gmail was already open.
